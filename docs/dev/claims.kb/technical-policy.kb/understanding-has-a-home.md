# Each prediction item has a durable artifact in version control

Each prediction item ([PREDICTION]) should have some corresponding code or doc
in version control: a durable artifact representing the understanding. The item
names that artifact as text. There is no separate notes collection; the artifact
is wherever the understanding fits, such as the code that uses it, a comment
beside it, or a design doc.

An item with no artifact to name is the occasion to write one.
