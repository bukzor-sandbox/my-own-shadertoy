# Worked-out mental models are written down, one note per concept

When bukzor works out how a WebGPU concept fits together (bind group layouts
against pipeline layouts, buffer alignment, error scopes), it becomes a short
note in `docs/webgpu.kb/`, in bukzor's words. Claude reads the one note that
applies before touching that concept, so both get the model back later. The
collection is created with its first note.
