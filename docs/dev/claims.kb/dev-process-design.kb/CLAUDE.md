# dev-process-design.kb -- where a new file goes

Conventions: [llm-design-kb] over [llm-claims-kb]. One claim per file, under the
rung whose question it answers.

- A claim about how the work gets done goes here; a claim about what the toy is
  goes in `../design.kb/`.
- An imperative on Claude or bukzor goes in `../technical-policy.kb/`, citing
  the claim here that it serves.
- A process claim moving here from `../design.kb/` is moved, with its `why:`
  citations swept, and never copied.
