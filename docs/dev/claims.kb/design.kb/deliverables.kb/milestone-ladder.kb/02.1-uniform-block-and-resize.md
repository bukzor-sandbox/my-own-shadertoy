# 2.1: a uniform block carries time, resolution, and mouse; the canvas resizes

Uniform block for time, resolution, mouse: laid out by hand first, then
computed. Resize lands here: the canvas tracks its displayed size and what
depends on that size follows it, so a shape drawn from `resolution` stays round
and sharp as the window changes.

> visibly different when resize is handled correctly.

Packages: `program/uniform-layout`, `gpu/uniform-buffer`, and resize in
`gpu/canvas-surface`.
