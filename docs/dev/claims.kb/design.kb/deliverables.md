# Deliverables

How it gets built, in what order. A **milestone** is one increment: one session,
one green commit. Milestones are numbered `N.M` so a split inserts a
sub-milestone without renumbering. A **tripwire** is a deliverable scheduled on
an occasion instead of a position in the ladder.
