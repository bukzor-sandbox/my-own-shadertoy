# When TypeScript lacks or mistypes a WebGPU API

A typecheck error or a missing member on a WebGPU type that the spec or the
browser does have.

Propose [WEBGPU_TYPES_PACKAGE] to bukzor: add `@webgpu/types`, name it in the
`types:` of `tsconfig.base.json`, and amend the sentence in
`DEPENDENCY_DIRECTION` on where the types come from.
