# When laying out buffers or writing matrix math

Computing struct offsets or alignment for buffer data, writing vector or matrix
math, or declaring typed buffer schemas.

If bukzor has already done this kind of work by hand once, raise
[HELPER_LIBRARIES], since a library may now do it. Otherwise the hand-written
version is the lesson; say nothing.
