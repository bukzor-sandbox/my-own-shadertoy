# Before copying code a third time

Code with two copies already gets shared now, not copied ([THIRD_USE]); in a
kept group, the sharing is bukzor's to design.

When the code is `assert`, also mention [ASSERT_LIBRARY] to bukzor, at low
priority: can `tiny-invariant` be told to keep its messages?
