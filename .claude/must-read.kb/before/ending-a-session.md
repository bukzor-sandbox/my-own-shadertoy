# Before ending a session

The session is wrapping up: a milestone landed, bukzor is signing off, or
context is running out.

- Leave the increment green and committed, or say plainly that it is not
  ([GREEN_INCREMENT]).
- Add this session's prediction items to `.claude/todo.md` ([PREDICTION]), each
  naming its artifact, or writing one where none exists
  ([UNDERSTANDING_HAS_A_HOME]).
