# must-read.kb -- this repo's trigger bank

Each entry's path names an occasion, and the root `CLAUDE.md` has every session
list the bank, so an occasion is recognized when it arrives. Conventions:
[llm-must-read-kb].

Each entry serves a claim in `docs/dev/claims.kb/` that binds an act to an
occasion, most often a tripwire: the claim holds the reasoning, and the entry
names the occasion and the act. A tripwire's entry retires with its `todo:`. A
reminder bound to one directory belongs in that directory's `CLAUDE.md` instead,
which loads when the work is there.

[llm-must-read-kb]:
  https://github.com/bukzor/bukzor-agent-skills/blob/main/llm-must-read-kb/SKILL.md
